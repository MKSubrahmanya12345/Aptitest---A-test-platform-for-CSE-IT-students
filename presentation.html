What is AptiTest?

AptiTest is a full-stack web application designed for aptitude test preparation, featuring both Student and Admin portals with real-time testing, analytics, and payment integration.

🎯 Core Purpose

Enable students to practice aptitude tests across multiple categories, track their performance over time, and compete on leaderboards while providing admins with comprehensive question management and student monitoring tools.

System Architecture

🏗️ Three-Tier Architecture

1. Presentation Layer

  • React SPA with Vite
  • Responsive Design
  • Theme Context (Light/Dark)
  • Toast Notifications

2. Application Layer

  • RESTful API (Express)
  • JWT Auth Middleware
  • Role-based Access Control
  • Payment Webhooks

3. Data Layer

  • PostgreSQL Database
  • Relational Schema Design
  • Indexed Queries
  • Transaction Support

🔄 Data Flow

Client → Axios → API → TypeScript Services → Database → JSON Response → React State

Database Schema

Table Purpose Key Fields
users User accounts id, email, password, role, status, email_verified
questions Approved questions id, category, difficulty, question_type, correct_answer(JSON)
review_pending_questions Pending approval id, status, parser_confidence
test_templates Test configurations id, name, difficulty, count, is_paid, price_paise
test_sessions Test attempts id, user_id, status, score, server_expires_at
test_session_questions Session questions linking session_id, question_id, question_order, is_viewed
test_session_answers User answers session_id, question_id, user_answer(JSON), is_correct
payments Payment records id, user_id, stripe_payment_intent_id, status

🔗 Key Relationships

users → test_sessions → test_session_questions ↔ questions

test_sessions → test_session_answers (composite PK: session_id + question_id)

users → payments | users → test_templates (created_by)

Stripe (Alternative)

  • Secure checkout

🔒 Payment Flow

  1. User selects paid template
  2. Server creates order/intent
  3. Checkout modal opens
  4. User completes payment
  5. Server verifies signature
  6. Access granted instantly

✨ Features

  • ₹1 test payment (minimal)
  • Idempotency protection
  • Duplicate payment prevention
