What is AptiTest?

AptiTest is a production-ready, full-stack web application designed for aptitude test preparation. It features dual portals for Students and Admins with real-time testing, comprehensive analytics, and integrated payment processing.

?? Project Vision

To create an intuitive, scalable platform where students can practice aptitude tests across multiple categories, track their performance over time, and compete globally - while giving administrators powerful tools to manage content and monitor progress.

Payment Integration

?? Razorpay Payment Flow

  1. User selects paid template
  2. Client calls /create-order
  3. Server creates Razorpay order
  4. Checkout modal opens
  5. User completes payment
  6. Razorpay calls handler
  7. Client sends to /verify
  8. Server verifies signature
  9. Access granted!

?? Key Features

  • Test mode: Rs 1 payments
  • Idempotency key prevents duplicates
  • HMAC signature verification
  • Instant access after success
  • Access persisted in database

??? Security Measures

  • Webhook signature verification
  • Order ID unique per attempt
  • Payment status tracking

Challenges & Solutions

?? Challenge 1: Test Timer Synchronization

Client-side timer could be manipulated, causing unfair advantages or premature submission.

? Solution: Server-Authoritative Timer

Implemented server_expires_at timestamp stored in database. Client fetches expiry time and calculates remaining seconds. Auto-submit triggers when server time expires, not client time.

?? Challenge 2: Multi-Question Type Rendering

8 different question types required unique UI components and answer handling logic.

? Solution: Dynamic Component Rendering

Created switch statement renderer based on question_type field. Each type has dedicated input component (MCQ radio buttons, fraction inputs, ratio fields, etc.) with normalized answer format.

14 / 20

More Challenges & Solutions

?? Challenge 3: Payment Security

Preventing duplicate charges and ensuring payment verification integrity.

? Solution: Idempotency & Signature Verification

Implemented UUID-based idempotency keys stored in database. Razorpay webhook signatures verified using HMAC with secret key. Database unique constraints prevent double-charging.

?? Challenge 4: State Management During Tests

User might refresh, close tab, or lose connection during active test.

? Solution: Auto-Save & Session Recovery

Answers auto-saved on every change via API. beforeunload event warns user. Session stored in database with status tracking. Users can resume in_progress sessions on re-login.

?? Challenge 5: Role-Based Access Control

Different features accessible to students vs admins requiring secure enforcement.

? Solution: JWT Claims + Middleware

JWT tokens include role claim. Express middleware validates role for protected routes. Frontend route guards redirect unauthorized access. Role checked on both client and server.
